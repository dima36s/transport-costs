# Учёт рейсов, продаж и хранения

Веб-приложение для учёта доходов от рейсов, продаж и хранения грузов и затрат на них.

**Открыть:** https://dima36s.github.io/transport-costs/

## Что умеет

- **Рейс** — дата, маршрут, водитель, стоимость, вид оплаты (безнал / нал / наш груз), комментарий.
- **Продажа** — дата, покупатель или за что, сумма, оплата (безнал / нал), комментарий.
- **Хранение** — доход от хранения груза клиента: дата, клиент, груз, срок хранения (с — по), сумма, оплата, комментарий.
- **Расход** — дата, статья, направление (рейсы, продажи, хранение или общие), сумма, комментарий.
- **Два вида итогов.** «Всё» — общий остаток: рейсы + продажи + хранение − все расходы, с таблицей по направлениям. «Рейсы», «Продажи», «Хранение» — у каждого направления свой доход, свои расходы и свой остаток; общие расходы входят только в «Всё».
- **Просмотр по неделям, месяцам, годам** и за произвольный период: график по дням / неделям / месяцам, разбивка по водителям, покупателям или клиентам, по виду оплаты и статьям расходов, сравнение с прошлым периодом, НДС с безналичных поступлений.
- **Журнал** с поиском, правкой и удалением (удаление можно отменить).
- **Отчёт в Excel** за выбранный период и направление: «Сводка» (итоги, по направлениям, по оплате, по водителям / покупателям / клиентам, по статьям, динамика) и листы с записями. Есть печать / сохранение в PDF.
- **Телефон и планшет:** на телефоне форма открывается кнопками «+ Рейс / Продажа / Хранение / Расход» внизу экрана, журнал показан карточками.
- **Загрузка из Excel** — журнал в формате «N, Дата, Рейс, Водитель, Стоимость, Комментарий» (все листы, плюс колонки «Расходы» и «За что»). Повторная загрузка того же файла дублей не создаёт; спорные строки показываются перед загрузкой. Продажи и хранение вносятся через форму.

При первом открытии новой версии старые расходы получают направление по статье: топливо, платные дороги, ТО и ремонт, штрафы — «Рейсы», закупка товара — «Продажи», остальное — «Общие». Направление можно поменять в любом расходе.

## Где хранятся данные

В базе данных браузера (IndexedDB) на том устройстве, где открыто приложение. На сервер ничего не отправляется. Чтобы перенести данные на другой компьютер или подстраховаться, используйте «Данные и настройки → Сохранить копию базы» и «Восстановить из копии».

Слой хранения вынесен в `js/db.js` — для общей базы на нескольких пользователей его можно заменить на серверную (например, Supabase/PostgreSQL), не трогая интерфейс.

## Устройство

Статический сайт без сборки: `index.html`, `css/app.css`, модули в `js/`. Библиотеки лежат в `vendor/`: [Dexie](https://dexie.org) 4.4 (IndexedDB) и [ExcelJS](https://github.com/exceljs/exceljs) 4.4 (импорт и отчёт, загружается по требованию).

Локальный запуск: `python3 -m http.server` в папке проекта и открыть http://localhost:8000.
